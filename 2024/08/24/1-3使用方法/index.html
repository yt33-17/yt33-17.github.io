git使用指令

指令 说明
git init 初始化
git clone +ssh地址 克隆远程仓库到本地
cd +远程仓库名 进入远程仓库目录
git add . 将工作区的所有文件添加到暂存区（也可指定文件）
git commit -m “提交信息” 将暂存区的文件添加到本地仓库
git push 提交到远程仓库
