1、GEC6818开发板简介

GEC：广州粤嵌

6818：开发板的型号，该开发板使用的处理器是三星S5P6818处理器
该处理器的内核是ARM CORTEX A53
所以，该开发板是一块ARM开发板，只能执行ARM指令集的程序

连接成功了，有可能还是无法控制开发板，有以下情况：

情况一：开发板开机以后会显示一个登录界面，并且在 SecureCRT 中输入命令无法执行，无法识别

原因及解决办法：此时开发板正在运行一个演示程序，键盘上的输入都当做程序运行时的输入，
按Ctr + C 可以结束正在运行的程序

情况二：开机以后，键盘输入任何字符都没有反应

原因及解决办法：可能是数据线断开了
也有可能是开发板没有开机
也有可能是波特率设置错误，检测波特率，设置为115200
有可能是数据线接触不良，更换数据线

3、传输文件到开发板上去

1.在SecureCRT中输入rx命令，让开发板进入接收文件的状态，用法如下
rx 文件名
如：
rx hello

​ 输入完rx命令以后，开发板会进入接收文件状态，此时会提示 CCC…
​ 每隔一段时间，就会添加一个C，如果长时间没有传输文件，就会传输失败
​ 所以，在输入完rx命令以后，应该要尽快地将要传输的文件发送给开发板

2.发送文件到开发板上去
方法一：选中要发送的文件，拖拽到SecureCRT中，松开鼠标，选择“发送Xmodem”

​ 方法二：在SecureCRT的菜单栏中，找到“传输”，选择“发送Xmodem”，选择要发送的文件，点击发送

​ 等待文件的传输进度到100%，文件传输完成，按回车键结束文件传输

​ 方法三：使用U盘来传输文件，并不是所有U盘都能使用
​ 将U盘插入电脑，将要传输的文件拷贝到U盘中
​ 将U盘插入开发板的USB口，在SecureCRT中会加载U盘的信息
​ 确认U盘是否自动挂载成功：
​ ls /mnt/udisk
​ 如果能够列举出U盘中的文件，那么U盘挂载成功
​ 否则，换个U盘再试

​ 将U盘中需要拷贝的文件拷贝到开发板中去：
​ cp /mnt/udisk/文件名 拷贝到开发板的哪个位置
​ 如：
​ cp /mnt/udisk/hello /
​ 将U盘中的hello这个文件拷贝到开发板的根目录(/)

注意：开发板是一种嵌入式设备，所以它没有配置编译环境，因此开发板上无法编译代码
但是它只能运行ARM指令集的程序文件，所以传输到开发板上去的通常是ARM版本的可执行文件或者图片、音视频、库文件等。

4、运行程序文件

在运行开发板上的程序时，有可能会报错，如：

​ -/bin/sh: ./hello: Permission denied

原因：
通过rx命令传输过来的新文件，默认是没有可执行权限的
所以，直接去运行会报错：权限不够
此时就需要给文件添加可执行权限

解决办法：
chmod +x hello

在运行程序的时候，有可能会报以下的错误：
./hello: line 1: syntax error: unterminated quoted string

原因：
开发板的处理器是一个ARM处理器，它只能运行ARM指令集的程序
但是传输过来的文件不是ARM指令集的程序，所以无法运行

解决办法：
如果程序是要放到开发板上去运行的，那么在编译的时候需要使用交叉编译器来进行编译
如：
arm-linux-gcc hello.c -o hello
通过交叉编译器编译后的程序，才能放到开发板上去运行

6、在屏幕上显示颜色

在Linux中一切皆文件，所以屏幕也是通过文件来操作的

在开发板中有一个特殊的文件，这个文件中存储了屏幕上所有像素点的颜色值

称之为帧缓冲设备文件

这个文件在开发板中的存储位置为：/dev/fb0

这个文件的大小为：800x480x4

​ 像素点：屏幕上最小的发光单元
​ GEC6818开发板屏幕分辨率为：800x480
​ 也就是说，该屏幕上一共有480行像素点，每一行有800个像素点

如何描述像素点的颜色值？
用一个32位(4字节)的整数来表示一个颜色值，这32位数据可以分成4组，没一组占8位
分别表示：a(透明度) r(红) g(绿) b(绿)
