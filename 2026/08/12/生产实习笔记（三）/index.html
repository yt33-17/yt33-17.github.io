1、内存映射

将一个文件或者设备映射到内存中去，即，在内存中分配一块存储空间，这个空间的大小通常等于文件的大小，文件中的每个存储单元在内存中都能找到一一与之映射的存储单元。原来需要通过文件IO来访问的操作，可以直接通过内存来访问，大大地提高数据的访问速度！

使用mmap()函数来建立映射，使用munmap()函数来解除映射释放内存。

2、显示图片

图片通常指图片文件，图片文件中存储了图片的信息以及图片上所有像素点的颜色值

所以，要显示图片只需要将图片中所有像素点的颜色值读取出来并显示到屏幕上就可以了

事实上没这么简单，图片有很多的格式，不同的图片格式在保存数据的时候采用的算法不同，
所以，针对不同的图片格式需要用不同的算法来处理！

其中有些图片格式还涉及压缩算法，需要用第三方库来进行解压缩

常见的图片格式有：jpg jpeg png bmp gif等

其中有一种图片格式比较特殊，它通常没有压缩算法，这种图片格式就是bmp图片格式

5、蜂鸣器

5.1、安装蜂鸣器驱动

​ 将 环境/LED灯_蜂鸣器驱动/pwm.ko 将这个驱动文件通过rx命令传输到开发板的根目录
​ 以下操作在开发板中执行：
​ cd /
​ rx pwm.ko 

传输完成以后执行以下的步骤：
    vi /etc/profile
    将光标移动到 source /IOT/driver_ko/insmod_driver.sh 这一行的前一行
    按 i 键，进入编辑模式，按回车键新开一行，写入以下命令
        insmod /pwm.ko
    如果不想让开发板一启动就运行演示程序，将以下两行代码注释掉：
        cd /IOT
        ./iot
        在这两个的行首加上一个#就可以了，如：
            # cd /IOT
            # ./iot
    按ESC键，退出模式
    输入":wq"进行保存并退出，注意输入法要切换成英文输入法
    重启开发板，查看驱动是否自动安装完成    =>  pwm

5.2、蜂鸣器的使用方法

​ 打开蜂鸣器设备文件(/dev/pwm)
​ 写入控制命令：一个字节的数据，1表示工作，0表示停止
​ 关闭蜂鸣器设备文件

6、LED灯

6.1、安装LED灯驱动

​ 和蜂鸣器驱动安装步骤类似，只是LED驱动的名称为：led_drv.ko

将 环境/LED灯_蜂鸣器驱动/led_drv.ko 这个驱动文件通过rx命令传输到开发板的根目录，以下操作在开发板中执行：
    cd /
    rx led_drv.ko

传输完成以后执行以下的步骤：
    vi /etc/profile
    将光标移动到 source /IOT/driver_ko/insmod_driver.sh 这一行的行首
    按 i 键，进入编辑模式，按回车键新开一行，写入以下命令
        insmod /led_drv.ko
    按ESC键，退出模式
    输入":wq"进行保存并退出，注意输入法要切换成英文输入法
    重启开发板，查看驱动是否自动安装完成    =>   led_drv

6.2、LED灯的使用方法

​ 打开LED设备文件(/dev/led_drv)
​ 写入控制命令：一共有两字节的数据 char cmd[2] = {data0,data1};
​ data0：用来控制LED灯的状态，1表示点亮，0表示熄灭
​ data1：用来控制LED灯的序号
​ 在开发板的右侧(屏幕下面)有4个LED灯，分别是D7D10
​ D7被占用了，通常控制不了，因此能够使用的是D8D10
​ 对应的编号就是8~10
​ 关闭LED设备文件
